
# コトミア プライバシーポリシー

「コトミア」（以下「本サービス」といい、その運営者を「当方」といいます）は、本サービスにおけるユーザーの個人情報および利用者情報（以下あわせて「利用者情報」といいます）の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。本サービスは、モバイルアプリケーションとして提供されます。

## 1. 取得する情報

本サービスは、以下の情報を取得します。

- **アカウント情報**: Apple のサインインを利用する場合、Apple から提供される識別子およびメールアドレス（ユーザーが「メールを非公開」を選択した場合は Apple のプライベートリレー用アドレス、またはメールアドレスなしとなることがあります）。メールアドレスで登録する場合は、メールアドレスおよびパスワード（パスワードはハッシュ化して保存され、当方は復元できません）。
- **音声データ**: ユーザーが本サービス上で録音した音声（m4a 形式）。
- **音声から生成されるデータ**: 音声を文字起こししたテキスト、およびAIによる評価・診断・フィードバックの結果。
- **利用状況・設定情報**: 診断・トレーニングの回答内容やスコア、リマインド通知の設定、有料プランの契約状態など、本サービスの利用に伴い生成される情報。
- **利用状況データ（分析用）**: 本サービスの品質向上のため、画面の表示履歴、ボタン操作、録音の完了・AI評価の完了などの操作イベント、有料プランの購入状況、アプリのバージョン、端末の機種・OS のバージョン、および当方が発行する内部識別子を取得します。録音した音声、文字起こしテキスト、AI のフィードバック本文、メールアドレス、氏名は、分析用データには含まれません。
- **課金情報**: 有料プランの購入・更新・解約に関する情報（購入した商品、購入日・有効期限等）。クレジットカード番号等の決済情報は Apple が処理し、当方および当方のバックエンドは取得・保持しません。

本サービスは、広告目的のトラッキングおよび広告識別子（IDFA）の取得を行いません。第三者の分析サービスは、「3. AIによる処理および第三者への提供」に記載する範囲でのみ利用します。

## 2. 利用目的

当方は、取得した利用者情報を以下の目的で利用します。

1. 本サービスの提供・維持・運営（音声の文字起こし、AIによる評価・診断・フィードバックの生成を含みます）
2. アカウントの認証・管理
3. 有料プランの提供および契約状態の管理
4. ユーザーからのお問い合わせへの対応
5. 本サービスの品質向上・改善（利用状況の分析、機能の利用傾向や離脱箇所の把握、および個人を特定できない形での統計的分析を含みます）
6. 不正利用の防止

## 3. AIによる処理および第三者への提供

1. 本サービスは、音声の文字起こしおよびその評価、ならびに利用状況の分析のために、以下の外部事業者のサービスを利用します。ユーザーの音声データおよび文字起こしテキストは、文字起こし・評価の処理のために当該事業者に送信されます。

   | 事業者 | 用途 | 送信される主なデータ | 所在国 |
   |---|---|---|---|
   | OpenAI, L.L.C.（OpenAI） | 音声の文字起こし（Whisper）および評価・診断（GPT-4o） | 音声データ、文字起こしテキスト、お題等の文脈情報 | 米国 |
   | Supabase, Inc.（Supabase） | データの保存・認証基盤（データベース・ストレージ・認証） | 本ポリシーに記載の利用者情報 | 日本（東京リージョン） |
   | RevenueCat, Inc.（RevenueCat） | サブスクリプション状態の管理 | ユーザー識別子（当方が発行する内部ID）、購入・課金に関する情報 | 米国 |
   | PostHog, Inc.（PostHog） | 利用状況の分析（プロダクト分析） | 前記「利用状況データ（分析用）」、ユーザー識別子（当方が発行する内部ID） | 米国 |
   | Apple Inc.（Apple） | サインイン認証および App Store 課金 | 認証トークン、購入・決済情報 | 米国等 |

2. 本サービスのデータベースおよびストレージは Supabase の日本（東京）リージョンに保管されますが、音声の文字起こし・評価（OpenAI）、サブスクリプション管理（RevenueCat）および利用状況の分析（PostHog）等の処理に伴い、利用者情報の一部が日本国外（米国等）で処理されることがあります。ユーザーは、本サービスの利用にあたりこれに同意するものとします。
3. 当方は、法令に基づく場合を除き、上記の目的の範囲を超えて、ユーザーの同意なく利用者情報を第三者に提供しません。

## 4. 保存期間

1. アカウント情報および本サービスの利用に伴い生成される情報は、原則としてユーザーがアカウントを削除するまで保存されます。
2. 録音した音声データおよび文字起こしテキストは、ユーザーがアカウントを削除するまで、本サービスのストレージに保存されます。
3. アカウント削除後も、AIの利用コストの集計等のために、個人を特定する内容を含まない利用ログを保持することがあります。当該ログには当方が発行する内部識別子が含まれることがありますが、氏名・メールアドレス・音声・文字起こし等の内容は含まれません。
4. 分析用の利用状況データは、アカウント削除後も分析サービス（PostHog）上に一定期間保持されることがあります。当該データには当方が発行する内部識別子以外に個人を特定できる情報は含まれません。削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

## 5. データの保管とセキュリティ

1. 利用者情報は、Supabase の提供するインフラ上に保管されます。音声データは非公開のストレージに保存され、各ユーザーは自己のデータにのみアクセスできるようアクセス制御が行われます。
2. 当方は、利用者情報の漏えい、滅失または毀損の防止その他の安全管理のために、必要かつ合理的な措置を講じます。

## 6. アカウントおよびデータの削除

1. ユーザーは、本サービス内の「アカウントを削除」機能から、いつでもアカウントおよび関連データを削除できます。
2. アカウント削除時には、以下の処理が行われます。
   - Apple のサインイン連携の失効（Apple への revoke リクエスト）
   - ストレージに保存された当該ユーザーの音声データの削除
   - アカウント、プロフィール、診断・トレーニングの記録、その他関連データの削除
3. 有料プランのサブスクリプションは、アカウントを削除しても自動的には解約されません。解約は App Store の設定から別途行ってください。

## 7. ユーザーの権利

ユーザーは、当方に対し、自己の個人情報の開示、訂正、追加、削除、利用停止等を請求することができます。ご希望の場合は、下記のお問い合わせ先までご連絡ください。

## 8. 通知について

本サービスのリマインド通知は、ユーザーの端末内で動作するローカル通知です。プッシュ通知のための識別子（プッシュトークン）を当方のサーバーに送信することはありません。通知の設定は、本サービスまたは端末の設定からいつでも変更できます。

## 9. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。変更後の本ポリシーは、本サービス上または当方所定の方法で告知した時点から効力を生じます。

## 10. お問い合わせ

本ポリシーおよび利用者情報の取扱いに関するお問い合わせは、kotomia.official@gmail.comまでご連絡ください。
